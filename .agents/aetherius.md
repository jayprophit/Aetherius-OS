# Aetherius agent brief

This repository is coordinated through the local Aetherius hive.

- Use the `aetherius` MCP server for `hive_work_log`, `hive_work_summary`, `knowledge_search`, `knowledge_read`, `knowledge_write`, `graphify_query`, `rea_capabilities` and `supervisor_status`.
- Before exploring code, query the Graphify graph with `graphify query "<question>"`.
- Claim a hive task before editing its files. Record evidence when done.
- Free models only. Never use a paid model, plan or provider.
- Never put credentials in a note, task, message or commit.
- Do not commit or push while another agent holds the `supervisor.lease`.
