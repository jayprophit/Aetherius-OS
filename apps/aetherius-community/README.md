# Aetherius OS Community

The Aetherius OS Community application: the feed, the groups, the chat and the events. An integrated application domain of the one Aetherius ecosystem, not a platform of its own.

**Registered, not built.** The scope is recorded and the primitives it
needs are mapped in `docs/APPLICATION-SHARED-PRIMITIVES.yaml`.

This is an integrated application domain of the one Aetherius
ecosystem. It does not get its own account system, its own billing
system or its own search index: the primitives it uses belong to the
projects the map names, and this application is a consumer of them.

Named as a first-party application in the Figma handoff of 17 October 2026. The shared primitives are in docs/APPLICATION-SHARED-PRIMITIVES.yaml: the accounts, groups, messaging, permissions and moderation are the ones the rest of Aetherius uses, and the decentralised messaging project is the reference for the messaging primitive rather than a second implementation of it.

## What it will be

A future Aetherius OS application for people and teams: the feed, the groups, the chat and the events.

## Where it comes from

The Figma handoff's screen family table lists Community with the feed, groups, chat and events, and the account, message, post and moderation primitives.
