# Security Policy

## Reporting a vulnerability

If you find a security problem in Aetherius OS, please report it privately
rather than opening a public issue, using the private vulnerability reporting
on the GitHub repository:

- `https://github.com/jayprophit/Aetherius-OS/security/advisories`

Include the version or commit you tested, the steps to reproduce it, and the
impact you observed. Please do not include credentials, tokens, or other
secrets in the report — describe what you needed instead.

We will acknowledge a report, investigate, fix, and disclose after a fix is
available. We ask reporters to avoid public disclosure before a fix ships so
users are not exposed.

## Supported versions

| Version | Supported |
|---|---|
| `0.1.0` (free self-hosted web/PWA developer preview) | Best effort — security fixes are applied as commits on `master` |
| Anything older than `0.1.0` | Not supported |

There is no paid support tier. The preview is free and self-hosted; the
operator of a deployment is responsible for keeping it current.

## How the system is built to be safe

- **No credentials in the build.** The Vite bundle carries no API key. Remote
  AI providers are only used with a runtime-supplied session credential, and
  the default AI path is a local Ollama instance.
- **Fail-closed sync.** The Cloudflare sync worker returns `503` for every
  protected route when its token is unset or too short, compares tokens in
  constant time, bounds request bodies, and only answers CORS for explicit
  allowlisted origins.
- **Deterministic merge.** Sync conflicts resolve by a total ordering
  (timestamp, tombstone, revision hash, device id), and losing values are
  preserved in a conflict log rather than silently overwritten.
- **Secret scanning in CI.** `npm run secret-scan` scans the repository for
  embedded credentials before merge; allowlisted files each state their
  reason.
- **No network by default.** The shell renders provider-dependent data as
  empty states until a backend is connected. It does not phone home.

## Scope of this policy

- The Aetherius OS shell and its application slices (`apps/`).
- The sync worker (`apps/aetherius-cloud/worker/`).
- The compute kernel (`kernel/compute/`).

Third-party applications bundled in the workspace (LedgerLands, Poietek,
football-card-game) keep their own repositories and advisories.

## What we will not do

- We do not pay bounties in this preview.
- Reports generated by automated scanners with no reproduction evidence are
  triaged but may be closed as `NO_INFORMATION`.
