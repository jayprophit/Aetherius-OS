# Release Evidence

Machine-readable evidence used by `scripts/release-gate.mjs`:

- `sbom.cdx.json` — generated CycloneDX SBOM (`node scripts/release-sbom.mjs`).
- `gate-report.json` — latest gate output (generated by the command below).

This directory is outside `dist/` so a build cannot delete the evidence.

```sh
node scripts/release-sbom.mjs
RELEASE_GATE_OUT=release/evidence/gate-report.json node scripts/release-gate.mjs
```

The files under `docs/evidence/` are audit/install/rollback/performance
templates. Do not mark them `PASS` without real evidence.
